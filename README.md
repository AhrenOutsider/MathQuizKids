# Math Quiz Kids

An educational Android game for kids built with Kotlin in Android Studio.

## What it does

- Shows 10 math questions per round
- Mixes addition, subtraction, and multiplication
- Gives instant feedback after each answer
- Tracks score out of 100
- Shows a final encouragement message and lets the player restart

## Open in Android Studio

1. Open this folder in Android Studio.
2. Let Gradle sync the project.
3. Run the app on an emulator or Android device.

## Main files

- `app/src/main/java/com/example/mathforkids/MainActivity.kt`
- `app/src/main/res/layout/activity_main.xml`
- `app/src/main/res/values/strings.xml`
